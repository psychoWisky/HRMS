Module-Wise Feature List

Every module implemented in the HRMS, broken down by feature with a short description of what it does. Shared for client review and sign-off.

Implemented

01 Authentication & Access

5 features
FeatureDescriptionStatus
Secure loginEmail + password login with hashed passwords; issues a session token for all further access.Implemented
Forced password changeNew accounts and password resets require the user to set their own password on first login.Implemented
Self-service password reset"Forgot password" flow to regain access without admin involvement.Implemented
Role-based permissionsEvery action in the system is gated by an explicit permission tied to the user's role — enforced on the server, not just hidden in the UI.Implemented
Department-scoped accessA Department Head only ever sees and manages employees, records and requests belonging to their own department — every other department is invisible to them.Implemented
